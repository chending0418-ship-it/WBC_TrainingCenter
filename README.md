# WBC Training Center

面向单一线下训练场馆的微信小程序。家长可以查看排课，为账户关联的一名孩子申请团课或私教，并查询预约详情和积分流水。教练可以查看自己的日程和所授课程的孩子姓名，也能设置自己的头像。管理员可以使用小程序管理端或 Web 后台，维护队员注册、排课、预约和积分。

## 1.1.0 公开课表与 Web 管理后台

棒球大图下展示本周课程，点「完整课表」可按周浏览已发布的团课，查看时间、课程名称、场地和授课教练。公开课表仅展示排课信息，满员的团课仍在原日期显示。家长登录后可以查看余位和私教时段，队员注册经管理员批准后即可提交预约。升级前资料完整的队员保留预约资格。修改已批准队员的姓名、出生年月或性别后，场馆会重新审核。

API 本地启动后，浏览器打开 [Web 管理后台](http://127.0.0.1:3000/wbctraining/admin)。教练、课程类型、排课、代约、队员审核和积分管理均与小程序共用俱乐部的数据。演示环境使用本地管理密码。生产环境通过服务变量 `WBC_WEB_ADMIN_PASSWORD` 单独配置 Web 管理密码，未配置时密码登录关闭。部署包须包含 `apps/web-admin` 和小程序的管理图标目录，并加载仓库里的 nginx 路由配置。

## 本地启动

需要 Node.js 24、npm 和微信开发者工具。在仓库根目录执行以下命令。

```sh
npm ci
npm run build:miniapp
npm run dev:api
```

API 默认启动在 `http://127.0.0.1:3000`，可访问 `/health` 检查。SQLite 文件默认位于 `apps/api/data/wbc.sqlite`，首次启动自动生成演示账户和排课。如需一份新的演示数据，可以给 API 指定新的 `WBC_DB_PATH`，例如 `WBC_DB_PATH=/tmp/wbc-fresh-demo.sqlite npm run dev:api`。

在微信开发者工具的「小程序 → 导入」选择 `apps/miniapp`，选择「不使用云服务」。本机演示连接 HTTP 本地 API 时，在工具的本地设置临时勾选「不校验合法域名……」，正式预览前恢复校验。小程序的 TypeScript 和静态文件由 `npm run build:miniapp` 输出到 `dist/`。修改源码后重新执行构建并在工具里编译。

### 验证家长端

在首页点「成员登录」，再点「家长登录」。家长端只显示「课表」「我的预约」「我的账户」。当前身份为管理员时，可在管理首页底部点「切换身份」。

1. 在「课表」选择未开课的团课或教练开放的私教时段，查看积分报价并提交申请。
2. 在「我的预约」查看待确认状态，在「我的账户」查看预留积分。管理员确认后才扣积分；拒绝或过期会释放预留。
3. 如需取消已确认的预约，请在开课前至少 6 小时联系管理员。管理员取消后会释放名额，带课程类型的班次按设置自动退积分；去「我的账户」查看退回流水。

退积分按原预约扣减计算，部分退还向下取整。比例为 0 或未选类型时不自动退积分。团课班次积分由管理员设置，私教可约 60、90 或 120 分钟，每位教练的三档积分由管理员分别设置。新队员首次预约前需提交姓名或昵称、出生年月和性别，并通过注册审核。「我的账户」还可选填联系人、查看演示协议和隐私说明。模拟登录服务仅供本机开发。

### 验证本地管理端

在登录页选择「管理员登录」，默认演示密码为 `wbc-demo-2026`。如需使用自定本地密码，在启动 API 时设置 `WBC_ADMIN_PASSWORD`。旧版演示库会在 API 启动时自动升级并保留已有预约和流水。

1. 在「课程类型」新增类型，填写名称、每位教练最多带几名学员和取消退还比例。全额退还为 100%，不退还填 0。随后在「排课管理」新增或编辑班次时选择类型，容量不能超过类型的人数上限。也可按周多选日期、同一天安排多个时段。在管理首页点「切换身份」后以家长登录，在「课表」核对课程出现。在「排课管理 → 私教时段」按教练和星期配置开放时间，也可按日期停用时段。在「教练管理」为该教练设置私教课程类型和积分。家长可以在「课表 → 私教」选择开放时段，管理员也可以代约。
2. 在管理首页查看「待确认预约」，确认或拒绝家长申请。也可在「预约管理」直接代约。选择至少 6 小时后开始的班次做取消测试，核对名额释放、退回积分和操作来源。
3. 在「积分管理」选择家长账户。线下入账需填积分、原因和凭证号或备注。人工调整可以增加或扣减可用积分，可关联本账户的一笔预约。家长端「我的账户」刷新后应看到新余额和流水。
4. 在线下入账或人工调整的流水旁点「冲正」，填写原因后确认。系统按原流水的反向金额新增一笔记录，两条流水互相可查。每笔最多冲正一次，调整或冲正后的余额须大于或等于零。

5. 在「教练管理」新增、编辑或停用教练；有未结束预约的教练需要先处理预约。到「排课管理 → 周期模板」编辑或停用模板，核对已预约、单独调整的班次保留。在「家长资料」可搜索孩子姓名、联系人、电话或账户 ID。

### 验证本地教练端

在登录页点「教练登录」，选择一名已启用的演示教练，查看「今天」和「本周」。先提交一笔对应教练的预约并由管理员确认，再以该教练登录，核对预约人数和孩子姓名。重新启动本地演示会话，选择另一名教练，核对只显示该教练自己的日程。

## 提交流程

每次变更都从最新的 `main` 新建分支，完成检查后推送分支并向 `main` 提交 Pull Request。通过 PR 合并后，将本地 `main` 同步到 `origin/main`。禁止直接推送 `main`。
