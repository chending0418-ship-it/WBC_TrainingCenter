# WBC Training Center

面向单一线下训练场馆的微信小程序。家长可以查看排课，为账户关联的一名孩子预约团课或私教，并查询预约和积分流水。教练只读查看自己的日程和所授课程的孩子姓名。管理员通过密码进入同一小程序的管理端，维护排课、预约和积分。

## 当前状态

仓库目前包含产品规划、需求和可点击的交互原型。原生小程序和 API 尚未搭建。V1 规划展示未来 30 天的排课，支持管理员在线下收款后录入积分，预约成功时立即扣减对应积分。取消后的积分退还规则以 PRD 中的待确认项为准。

## 本地开发

计划使用原生微信小程序（WXML、WXSS、TypeScript）、Node.js API 和本地 SQLite。Apple Silicon Mac 已验证微信开发者工具稳定版和 Node.js 24，完整环境检查见 [开发说明第 6 节](./02-产品需求与Codex开发说明.md#6-mac-开发环境自检codex-必须先执行)。本地阶段使用模拟登录和种子数据。正式上线时，API 和数据库将部署到自有上海服务器。

## 提交流程

每次变更都从最新的 `main` 新建分支，完成检查后推送分支并向 `main` 提交 Pull Request。通过 PR 合并后，将本地 `main` 同步到 `origin/main`。禁止直接推送 `main`。
